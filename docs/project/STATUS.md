## 更新协议

每次交接只更新相关任务行，并附：owner、目标、输入/输出契约、文件边界、验证命令/结果、状态、风险和下一个 owner。直接聊天得到的接口或需求决定，必须在同一工作回合回写到本文件或相应规格后才生效。跨 Agent 不得并行修改同一文件；只有主 Agent 可以合并任务或签核发布。
