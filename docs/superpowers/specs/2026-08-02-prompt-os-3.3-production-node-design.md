# Prompt OS 3.3 生产节点设计

日期：2026-08-02
状态：设计交接，等待 GPT-5.5 执行
目标版本：`3.3.0`

## 1. 这版只解决什么

3.3 合并 3.1 的营销文案方法和 3.2 的工作台链路，作为下一轮唯一执行基线。

目标不是多加节点，而是让现有 N1–N9 真正串起来：

```text
导入后整理：只保存素材和商品卡，零 AI
预备生成：N1–N7，生成商品身份、事实台账、1+8 Prompt，不生图
正式生成：缺 Prompt 或 Prompt 过期时自动补跑 N1–N7，N7 通过后生图
导入并自动出图：导入后直接走同一条预备 + 正式生成链
```

核心原则：

- 一个商品卡只产出一套 `1 张白底标准图 + 8 张营销图`。
- 卡内多张图共同参与这套图，可以是角度、颜色、规格、款式、包装、配件或细节。
- 第一张图是主参考；点击缩略图只预览，拖到第一张才改变主参考。
- AI 不要求员工解释“多图关系”；N2 自己归并同外观，区分不同颜色/规格/款式。
- 只有全部图片都不是有效商品图时才阻断。模型 Schema、`image_role`、`string`、JSON 错误是系统问题，先内部修复或兜底，不直接给员工看。
- 国家只限定语言、平台规则和禁用内容，不硬套“某国必须是什么场景”。场景由商品事实、消费者任务、项目/单品风格和 Style DNA 决定。

## 2. 工作台触发模型

### 2.1 导入后整理

员工上传图片/文件夹或输入 ERP SKU 后，点击“导入后整理”：

- 每张图片默认创建一个商品卡。
- 同项目重复图片或重复 SKU 跳过，不重复追加。
- 不调用 `gpt-5-nano`、`deepseek-v4-pro` 或 `gpt-image-2`。
- 商品名为空时保持空输入框，只显示占位：`可不填，预备生成时识别`。
- 用户可拖缩略图合并、拆分、排序；这些动作只把商品标记为“需要预备”，不自动跑 AI。

### 2.2 预备生成

员工点“预备生成选中商品”：

- 多个商品并发准备，单商品失败不影响其他商品。
- 前端显示脉冲进度：`识别图片 → 合并身份 → 整理事实 → 白底提示词 → 营销策划 → 逐张 Prompt → 规则检查 → 预备完成`。
- Prompt 槽位生成一个就展示一个，不等九个全完成。
- 低置信商品名不阻断；名称为空时由 N2 填入可改名称。

### 2.3 正式生成

员工点“正式生成选中商品”：

- 如果当前商品版本已有同配置、同素材、同 Prompt 的 N7 通过版本，直接生图。
- 如果 Prompt 缺失或过期，接口返回 `preparing`，自动补跑 N1–N7，成功后继续正式生成。
- 白底图先生成并归档；8 张营销图优先引用白底图，再按槽位需要加入最少原始参考图。
- 失败只重做失败项；历史 Prompt、生成图和审核记录不覆盖。

N2 之后，下游只读这些变量，不重新猜图片关系：

## 4. 每个节点的真实职责

| 节点 | 模型/执行器 | 输入 | 输出 | 失败边界 |
| --- | --- | --- | --- | --- |
| N1 逐图观察 | `gpt-5-nano-2025-08-07` | 单张我方图、员工/ERP 名称、补充信息 | 是否有商品、候选名、结构、颜色、数量、包装、配件、细节、使用关系、质量分 | 单图失败只标记该图；角色同义词内部映射；不给员工看 `image_role` |
| N2 身份归并 | `deepseek-v4-pro`，温度 0.3 | 当前卡全部 N1、图片顺序、人工/ERP 名称 | `product_family`、显示名、身份锁、`target_appearances`、主参考、冲突 | 只有全部图无有效商品或名称与图片核心冲突才阻断；`string` 占位清空或用 N1 兜底 |
| N3 事实台账 | `deepseek-v4-pro`，温度 0.2 | N2、员工补充、风格提示、规则上下文 | confirmed/observed/inferred、证据、风险、允许用途 | 价格、认证、疗效、容量、产地、质保等高风险内容不能靠推断进文案 |
| N4 白底编译 | `deepseek-v4-pro`，温度 0.4 | 身份锁、全部外观、事实、白底规则 | 英文白底图 Prompt、参考图计划、无文字约束 | 无可用我方参考图或白底规则冲突才阻断 |
| N5 营销导演 | `deepseek-v4-pro`，温度 1.6 | N2/N3、消费者上下文、8 槽、国家语言、平台、项目/单品风格、Style DNA | 每槽购买任务、文案策略、场景、动作、构图、外观覆盖、文案意图 | 策略重复、空泛话术、事实引用缺失先自动重写一次 |
| N6 单槽编译 | `deepseek-v4-pro`，温度 0.9 | 单槽 N5、事实、身份锁、语言、规则、参考图计划 | 目标语言可见文案、回译、自评分、英文 `gpt-image-2` Prompt | 文案不自然、歧义、语言错误先重写一次；文字锁不一致阻断 |
| N7 生成前闸门 | 确定性规则 + `deepseek-v4-pro`，温度 0.2 | N6 Prompt、文案、事实引用、规则、参考图、版本指纹 | pass/block、硬阻断、警告、可自动修复项 | 平台硬规则、事实幻觉、文字锁、版本过期直接阻断 |
| N8 修改导演 | `deepseek-v4-pro`，温度 0.4 | 圈选区域、问题标签、原 Prompt、身份锁 | 只改目标区域的差量 Prompt | 不改变圈外商品身份；仍过 N7 |
| N9 失败简化 | `deepseek-v4-pro`，温度 0.2 | Prompt 复杂度失败或允许重写的安全拒绝 | 更短但事实等价的 Prompt | 网络、余额、限流、权限不走 N9 |

## 5. 营销文案策略

用户视频里的方法被固定成 N5 的策略池。每张营销图只选一个主策略，不堆满。

| 策略 | 作用 | 输出变量 |
| --- | --- | --- |
| FAB 价值翻译 | 把商品事实翻译成用户收益 | `feature`、`advantage`、`consumer_benefit` |
| 场景占有 | 让用户脑中出现自己正在用的画面 | `user_job`、`mental_simulation` |
| 情绪触发 | 从麻烦/尴尬/不安转到安心/愉悦/从容 | `consumer_tension`、`emotional_shift` |
| 拟人表达 | 让商品用一句自然话跟消费者说话 | `product_voice` |
| 身份表达 | 让产品代表审美、品位或生活方式 | `identity_signal` |

八张营销图要求：

- 至少覆盖四种策略。
- FAB 至少一张。
- 拟人默认最多一张，除非商品天然适合拟人。
- 每槽必须引用至少一个当前商品事实或低风险推断。
- 禁用没有证据的空泛成品词：`品质生活`、`高级感`、`理想之选`、`premium quality`、`perfect for every moment`。

## 6. N5 到 N6 的创意结构

N5 不写最终 Prompt，只写创意 Brief：

```json
{
  "slot_order": 4,
  "chinese_slot_name": "功能说明图",
  "appearance_ids": ["appearance.001"],
  "decision_task": "让用户理解为什么这个收纳盒适合通勤带餐",
  "creative_strategy": {
    "mode": "scene_ownership",
    "source_fact_refs": ["fact.002"],
    "user_job": "午餐后把餐具干净收回包里",
    "consumer_tension": "外出餐具容易弄脏包内物品",
    "feature": "便携收纳盒",
    "advantage": "使用后能单独收纳",
    "consumer_benefit": "通勤午餐后不用担心包里被弄脏",
    "mental_simulation": "在办公室午餐后顺手放回盒子",
    "emotional_shift": "从尴尬凌乱变成安心整洁",
    "product_voice": "",
    "identity_signal": "自带餐也保持体面",
    "selection_reason": "该槽位最适合解决携带和收纳顾虑"
  },
  "scene_brief": {
    "main_scene": "办公室午餐后的整洁桌面",
    "main_action": "餐具被放回收纳盒旁",
    "composition": "商品居中，手部动作辅助，不遮挡主体",
    "lighting": "自然明亮",
    "props": ["便当盒", "餐巾", "水杯"],
    "avoid": ["价格", "认证", "夸大环保声明"]
  },
  "copy_intent": "一句话说明收纳后的安心感"
}
```

N6 再把它编译成：

- 目标国家语言的可见文案。不是中文直译，而是直接用目标语言创作。
- 回译中文/英文，用来检查意思是否顺。
- 英文画面控制 Prompt。
- 严格文字锁：可见文案逐行放进英文 Prompt，用引号包住，禁止图像模型翻译、增删或改写。

## 7. Style DNA 模板

用户给的 `Sunlit Coastal Product Blitz` 样例要学习结构，不复制内容。

Style DNA 标准字段：

```json
{
  "style_name": "",
  "style_anchors": [],
  "source_content_to_avoid": [],
  "visual_deconstruction": {
    "composition_logic": "",
    "subject_placement": "",
    "camera_perspective": "",
    "typography_system": "",
    "color_behavior": "",
    "texture_and_lighting": ""
  },
  "design_rules": [],
  "negative_prompt": []
}
```

应用规则：

- Style DNA 可以影响光线、色彩、构图、版式密度、字体气质和道具风格。
- Style DNA 不能新增商品事实，不能复刻竞品品牌、原文案、人物、布局、包装或 Logo。
- 国家不锁场景；风格和商品共同决定场景。
- 主图/白底图不使用营销 Style DNA；营销图才使用。

## 8. GPT Image 2 最终 Prompt 模板

最终提交 `gpt-image-2` 的单图 Prompt 控制在 3500 字符内，英文为主：

```text
Purpose: create a marketplace product listing image for {platform} in {market_language}.
Product identity to preserve: {shared_identity_lock}. Target appearances in this slot: {appearance_labels}.
Reference plan: use the completed white-background image first; use only these owned reference images for structure: {reference_image_roles}.
Scene: {main_scene}. Main action: {main_action}. Composition: {composition}. Lighting: {lighting}. Props: {props}.
Visible text: render exactly these lines, with no translation or extra words: "{line_1}" / "{line_2}" / "{line_3}".
Style direction: {style_anchors}. Keep the product accurate and commercially polished.
Hard constraints: no extra logos, no prices, no unsupported certifications, no medical or weight-loss claims, no QR codes, no watermarks, no copied competitor layout, no random text.
Output: {size}, {resolution}, photorealistic ecommerce advertising image.
```

白底图模板更短：纯白背景、完整商品、无新增文字、无水印、保持全部目标外观。

## 9. 员工可见错误

| 内部原因 | 员工看到 |
| --- | --- |
| 图片空白、全是风景、完全无商品 | `未识别到商品，请换一张更清晰的商品图` |
| 部分图片坏了 | `部分图片无法读取，可删除或重新上传` |
| N1/N2 Schema、枚举、JSON、`string` | `系统识别异常，请重试预备生成` |
| 名称与图片明显冲突 | `商品名称和图片可能不一致，请修改名称或换图` |
| 文案太空泛或重复 | 不展示，系统自动重写一次 |
| 平台硬规则或事实幻觉 | `当前图文不符合平台规则或商品事实，请修改 Prompt` |
| APIMart 限流/网络 | `出图服务暂时繁忙，请稍后重试` |

## 11. 完成验收

- 导入后整理零 AI。
- 预备生成并发可见，Prompt 逐槽加载。
- 一个商品卡多图输出 `target_appearances`，白底/总览覆盖全部外观。
- 单槽最终 Prompt 使用英文控制，目标语言文案逐字冻结。
- 8 张营销图至少四种策略、FAB 至少一张、重复场景签名为 0。
- 内部字段错误不出现在员工界面。
- 无当前 N7 通过 PromptVersion 时不得创建付费 Generation。
- 真实 1+8 付费图经人工审核，商品身份硬错误为 0，运营可用性至少 4/5。
