# Prompt OS 4.0 节点生产设计

日期：2026-08-02
状态：GPT-5.5 下一轮执行基线，尚未实现或发布
目标版本：`4.0.0`

## 1. 一句话结论

4.0 的目标不是再多加节点，而是让现有 N1–N9 真正串起来：导入只建商品卡；预备生成才识别、补名称、生成身份卡和 1+8 Prompt；正式生成必须使用当前商品、当前国家、当前图片顺序下 N7 通过的 Prompt；如果没有合格 Prompt，就自动预备后继续。

默认配置固定为：`Shopee 虾皮 / 东南亚通用 / 1:1 / 1K`。国家只控制语言、硬规则和禁用内容，不把场景锁死在某个国家。营销场景由商品事实、目标消费者、项目/单品风格提示词、Style DNA 和购买心理策略决定。

## 2. 工作台触发规则

| 用户动作 | AI 调用 | 后续 |
| --- | --- | --- |
| 导入后整理 | 0 次 | 只创建商品卡和素材，状态为“待整理” |
| 预备生成 | N1–N7 | 生成商品名、身份卡、事实台账、9 槽 Prompt，不生图 |
| 正式生成 | 有合格 Prompt 直接生图；没有或过期则先 N1–N7 | N7 通过后先白底，再营销图 |
| 导入并自动出图 | 导入后自动 N1–N7 + 生图 | 可识别商品继续；完全无法识别的商品单独失败 |

前端必须立即显示“已排队/识别中/Prompt 生成 x/9/白底生成/营销图 x/8”的脉冲进度。不能让用户点了以后像没反应。

## 3. 多图商品规则

- 每张图默认一个商品卡。
- 把图片拖进同一卡，即表示这些图共同生产一套 1+8。
- 卡内图片可以是角度、细节、包装、配件，也可以是不同颜色、规格或款式。
- 第一张图是主参考，用于确定主商品裁切和优先外观；点击缩略图只切换大图预览，拖到第一张才改变主参考。
- N1 分析全部图片；N2 输出 `product_family` 和 `target_appearances`，不用员工选择“多图关系”。
- 白底图和总览图必须覆盖全部 `target_appearances`；其他营销图可以展示子集，但整套 1+8 必须覆盖全部外观。
- APIMart GPT Image 2 最多支持 16 张参考图；生产默认不塞满。N6 每槽只选“白底图 + 当前槽位需要的最少原图”，避免所有图都被原始背景拖成重复构图。

`target_appearances` 示例：

```json
[
  {
    "appearance_id": "appearance.001",
    "label": "浅木色餐具套装",
    "asset_ids": ["asset_front", "asset_detail"],
    "role": "main",
    "visible_traits": ["筷子", "勺子", "收纳盒", "浅木色"]
  },
  {
    "appearance_id": "appearance.002",
    "label": "深色款餐具套装",
    "asset_ids": ["asset_dark"],
    "role": "variant",
    "visible_traits": ["深色手柄", "同类套装"]
  }
]
```

## 4. 统一变量总线

下游节点只消费上游结构化变量，不重新猜。

```json
{
  "cluster_id": "uuid",
  "platform": "shopee",
  "country": "东南亚通用",
  "language_policy": {"visible_text_language": "English or local default"},
  "size": "1:1",
  "resolution": "1K",
  "project_style_prompt": "整批风格提示词",
  "product_style_prompt": "单品风格提示词；不为空时替代项目风格",
  "manual_product_name": "",
  "erp_product_name": "",
  "product_notes": "材质、功能、消费者或特别要求",
  "assets": [{"asset_id": "asset_front", "order": 1, "role": "PRIMARY"}],
  "product_family": "",
  "target_appearances": [],
  "identity_lock": {},
  "fact_ledger": [],
  "style_dna": null,
  "rule_snapshot": {}
}
```

人工填写的商品名、SKU、补充资料是 `confirmed`，AI 不能覆盖。空商品名由 N2 补全并标记“AI 识别，可修改”。`string`、枚举差异、JSON/Schema 错误、`image_role` 不合预期都是系统问题，不能写进商品名或直接吓用户。

## 5. 九节点详细设计

### N1 逐图观察

- 模型：`gpt-5-nano-2025-08-07`
- 温度：低温
- 输入：单张我方图片、图片顺序、人工/ERP 名称、补充资料。
- 输出：候选商品名、可见商品、结构、颜色、数量、包装、配件、人物/道具、图片角色、置信度。
- 规则：只描述看见的东西，不推断材质认证、功效、价格或品牌。
- 失败：单图坏只标记坏图；全部图无有效商品才阻断。

Prompt 必须强调：

```text
你是跨境电商商品图观察员。只观察我方上传图片。输出严格 JSON。
不要把示例值 string 当结果。不要把背景道具当商品。
如果图片中有可销售商品，即使不是白底图，也要识别为 owned product reference。
```

### N2 商品身份与外观归并

- 模型：`deepseek-v4-pro`
- 温度：0.3
- 输入：全部 N1、图片顺序、人工/ERP 名称、补充资料。
- 输出：`product_family`、展示商品名、身份锁、`target_appearances`、主/辅参考图、冲突状态。
- 规则：同一卡不是强行单一外观；颜色/规格/款式要拆成多个 `target_appearances`。
- 失败：全部无有效商品，或手填名称与图片核心冲突。

身份锁只保存会影响图像一致性的内容：形状、部件数量、Logo/包装文字、颜色范围、配件关系、套装包含物、比例关系。不要输出“商品类别 string”这种无用项。

### N3 事实台账

- 模型：`deepseek-v4-pro`
- 温度：0.2
- 输入：N2、人工/ERP 资料、平台国家、规则快照。
- 输出：`confirmed / observed / inferred` 三类事实，带 `fact_id`、证据、风险、允许用途。
- 规则：能进图片文案的事实必须有 `fact_id`。高风险内容默认不能进文案。
- 失败：事实不足不阻断，除非商品身份也无法建立。

### N4 标准白底编译

- 模型：`deepseek-v4-pro`
- 温度：0.4
- 输入：身份锁、全部目标外观、主图、必要辅助图、尺寸、规则。
- 输出：英文白底图 Prompt、参考图计划、禁止项。
- 规则：无新增文字、无水印、无营销道具、无背景场景。多色/多款组合要在白底或总览中清楚展示全部目标外观。
- 失败：没有任何可用我方参考图，或规则禁止该白底生成。

### N5 八图营销导演

- 模型：`deepseek-v4-pro`
- 温度：1.6
- 输入：N2/N3、目标外观、平台国家、项目/单品风格提示词、Style DNA、8 个营销槽。
- 输出：每槽中文策划：购买问题、主策略、场景、动作、构图、appearance_ids、文案意图。
- 规则：不是写最终图片 Prompt，而是决定每张图为什么存在。
- 失败/重写：场景签名重复、外观覆盖不足、引用未知事实时自动重写一次；仍失败阻断当前商品。

五种必须内置的营销策略：

1. `fab_value`：商品事实 → 优势 → 用户收益。
2. `scene_ownership`：让用户脑内出现“我正在用”的画面。
3. `emotion_shift`：从麻烦、尴尬、不安转成轻松、安心、体面。
4. `personification`：商品用一句自然话跟用户说话，默认最多一张。
5. `identity_signal`：让商品代表审美、身份、生活方式或选择标准。

八张营销图至少覆盖四种策略，FAB 至少一张，拟人默认最多一张。禁止空泛话术：`品质生活`、`高级感`、`理想之选`、`Premium quality`、`Perfect for every moment`。

### N6 单槽本地化与生图编译

- 模型：`deepseek-v4-pro`
- 温度：0.9
- 输入：单槽 N5、N3 事实、目标语言、规则、白底图、必要参考图。
- 输出：目标语言可见文案、回译、自评分、英文 `final_english_image_prompt`、参考图选择。
- 规则：文案直接用目标语言创作，不中文逐字翻译；给 GPT Image 2 的画面控制必须英文。
- 失败/重写：语言不自然、文案空泛、事实引用不足、文字未锁进英文 Prompt 时自动重写一次。

最终 Prompt 必须包含：

```text
Subject identity lock
Target appearance ids
One main scene
One main action
Composition and camera
Lighting and material texture
Visible text: render exactly these lines, with no translation, no extra words:
"..."
Reference image plan
Do not add unverified claims, logos, prices, QR codes, watermarks, extra text
```

### N7 规则闸门

- 执行器：确定性规则 + `deepseek-v4-pro` 语义补充
- 温度：0.2
- 输入：N6 Prompt、可见文字、事实引用、规则快照、参考图计划、版本指纹。
- 输出：`pass/block`、硬阻断、警告、一次重写原因。
- 规则：确定性硬阻断优先，模型不能取消。
- 阻断：文字锁不一致、未知事实、平台硬规则、竞品图进入参考、Prompt 过期、无白底门禁。
- 自动重写：只允许空泛/重复/语言不顺这类低风险文案问题。

### N8 审核修改导演

- 模型：`deepseek-v4-pro`
- 温度：0.4
- 输入：圈选坐标、标签、审核说明、原 Prompt、身份锁、规则。
- 输出：只改目标区域的差量 Prompt。
- 规则：不改未圈选区域，不重写整张图；如果 APIMart 不支持精确 mask，就用受控标注参考图，不伪装成精确 mask。

### N9 失败简化

- 模型：`deepseek-v4-pro`
- 温度：0.2
- 输入：被拒 Prompt、失败分类、身份锁、规则。
- 输出：更短但事实等价的 Prompt。
- 规则：只处理 Prompt 复杂度或允许重写的内容安全失败。
- 不处理：网络、余额、限流、未知提交状态。

## 6. 1+8 槽位职责

1. 标准白底产品图：看清商品和全部关键外观。
2. 第二视角/结构图：补主图看不到的结构关系。
3. 核心卖点图：把最强事实翻译成用户收益。
4. 商品细节图：材质、接口、纹理、做工、包装细节。
5. 功能说明图：展示正确使用关系，不夸大。
6. 使用场景图：让用户产生“我正在用”的画面。
7. 模特/比例/适配图：按商品真实消费者适配人、宠物、儿童或空间比例。
8. 尺寸/包装/内容物图：解释套装、规格、包含物或多色多款。
9. 购买收尾图：用情绪、身份或生活方式完成转化。

## 7. Style DNA 使用规则

用户给的优秀 Prompt 样例拆成可复用结构：

- 风格锚点：光线、镜头、层次、材质、画面密度。
- 版式语言：标题位置、辅助标签、徽章、呼号、图文层级。
- 色彩行为：主色、辅助色、强调色、冷暖关系。
- 文字系统：主标题、辅助文字、微文案、弧形/标签式呼号。
- 禁止复制：原品牌、原商品、原故事、原文案、原布局、Logo、QR、水印。

Style DNA 只能影响画面语言，不能新增商品事实。比如“阳光海岸、高密度海报、白色手写标题、金色徽章”可以变成风格；“啤酒、IPA、限量 200 瓶、原品牌名”不能进入我方商品图。

## 8. 员工可见错误

| 内部原因 | 员工看到 |
| --- | --- |
| 全部图片无商品、空白、风景 | 未识别到商品，请换一张更清晰的商品图 |
| 部分图片损坏 | 部分图片无法读取，可删除或重新上传 |
| JSON、Schema、`image_role`、`string` | 系统识别异常，请重试预备生成 |
| 名称与图片明显冲突 | 商品名称和图片可能不一致，请修改名称或换图 |
| 空泛/重复文案 | 不展示，系统自动重写当前槽 |
| 事实幻觉或平台硬规则 | 当前图文不符合平台规则或商品事实，请修改提示词或补充资料 |
| APIMart 限流/网络 | 出图服务暂时繁忙，请稍后重试 |
| ERP Token/Session 过期 | 直接跳登录页 |
