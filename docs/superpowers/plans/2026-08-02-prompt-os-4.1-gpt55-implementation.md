# Prompt OS 4.1 GPT-5.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 Prompt OS 4.1：整理零 AI、正式生成自动预备、一卡多图共同生成一套 1+8、五策略营销文案、目标语言文字锁、N7 付费门禁和员工错误脱敏。

**Architecture:** 复用现有 Django、React、PromptVersion、ClusterAsset、analysis_snapshot、TanStack Query 和 dnd-kit。不新增表、依赖、Redis、WebSocket 或队列。后端统一变量总线和节点门禁；前端只展示商品卡、进度、Prompt 和可行动错误。

**Tech Stack:** Django 5.2、React + TypeScript + Vite、APIMart `gpt-5-nano-2025-08-07`、`deepseek-v4-pro`、`gpt-image-2`。

## Global Constraints

- 默认配置：`Shopee 虾皮 / 东南亚通用 / 1:1 / 1K`。
- `导入后整理` 不得调用任何 AI。
- `正式生成` 缺少当前 N7 pass Prompt 时必须自动预备并续接生成。
- 一个商品卡只产出一套 1+8；卡内全部图片共同参与。
- 第一张为主参考；点击缩略图只预览，拖动排序到第一位才改变主参考。
- N2 输出 `product_family`、`shared_identity_lock`、`target_appearances`。
- 国家只控制语言、规则和禁用内容，不限制场景创意。
- N5 温度 1.6；N6 温度 1.0；N2/N3/N7 低温。
- 不触碰 `docs/project/用户操作流程以及相关触发.md`。
- 不打印 Secret，不覆盖历史 Prompt/生成/审核，不删除或 skip 测试。
