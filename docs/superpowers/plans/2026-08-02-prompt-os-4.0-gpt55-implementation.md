# Prompt OS 4.0 GPT-5.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Prompt OS 4.0 节点、工作台触发、商品多图变量总线、营销文案、目标语言文字锁和正式生成门禁实现成可测试代码。

**Architecture:** 不新增表、依赖、Redis、WebSocket 或新队列。复用 `ClusterAsset`、`analysis_snapshot`、`PromptVersion`、现有上传/ERP/API、TanStack Query 和 dnd-kit。后端负责节点变量、归一化、N7 门禁和自动预备；前端负责紧凑工作台、缩略图预览/排序、浮层、进度和逐槽 Prompt 展示。

**Tech Stack:** Django 5.2、React + TypeScript + Vite、TanStack Query、dnd-kit、APIMart `gpt-5-nano-2025-08-07`、`deepseek-v4-pro`、`gpt-image-2`。

## Global Constraints

- 默认配置：`Shopee 虾皮 / 东南亚通用 / 1:1 / 1K`。
- 导入后整理零 AI；预备生成才跑 N1–N7；正式生成缺 Prompt 时自动预备后继续。
- 一个商品卡产出一套 1+8；卡内全部图片共同参与，N2 输出 `target_appearances`。
- 国家只限制语言、规则和禁用内容，不限制场景创意。
- N5 温度 1.6，N6 温度 0.9，N2/N3/N7 低温。
- 不触碰 `docs/project/用户操作流程以及相关触发.md`。
- 不打印 Secret，不覆盖历史 Prompt/生成/审核，不 skip/todo/delete 测试，不放宽断言。

- `platform_app/prompt_templates_v3.py`：4.0 版本、N1–N9 schema、完整 system prompt。
- `platform_app/services.py`：节点输入、归一化、错误脱敏、N7、自动预备、生成门禁。
- `platform_app/management/commands/seed_platform_templates.py`：发布 4.0 模板。
- `frontend/src/components/ProductCard.tsx`：商品卡、缩略图预览/排序/拖拽、状态。

- `frontend/src/types.ts`：appearance、copy、stage、snapshot 类型。
- `tests/test_prompt_os.py`、`tests/test_prompt_templates_v3.py`、现有前端测试：红绿验证。
- `PROGRESS.md`、`BLOCKED.md`、`docs/project/STATUS.md`：断点和交接。
