# Prompt OS 3.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把工作台、N1–N9、营销文案、目标语言文字锁和正式生成串成可用的 Prompt OS 3.3 链路。

**Architecture:** 不新增表、依赖、Redis、WebSocket 或新队列。复用 `ClusterAsset`、`analysis_snapshot`、`PromptVersion`、现有上传/ERP/API、TanStack Query 和 dnd-kit。后端负责状态、节点契约、PromptVersion 和生成门禁；前端只展示紧凑工作台、并发进度、浮层和逐槽 Prompt。

**Tech Stack:** Django 5.2、React + TypeScript + Vite、TanStack Query、dnd-kit、APIMart `gpt-5-nano-2025-08-07`、`deepseek-v4-pro`、`gpt-image-2`。

## Global Constraints

- 默认配置：`Shopee 虾皮 / 东南亚通用 / 1:1 / 1K`。
- 导入后整理零 AI；自动出图和正式生成缺 Prompt 时自动跑 N1–N7。
- 一个商品卡产出一套 1+8；卡内全部图片共同参与，N2 输出 `target_appearances`。
- 国家只限制语言、硬规则和禁用内容，不强制国家场景。
- N5 温度 1.6，N6 温度 0.9，其余语义节点按规格低温。
- 不触碰 `docs/project/用户操作流程以及相关触发.md`。
- 不打印 Secret，不覆盖历史 Prompt/生成/审核，不 skip/delete/放宽测试。

## File Structure

- `platform_app/prompt_templates_v3.py`：Prompt OS 版本、N1–N9 Schema、完整 system prompt seed。
- `platform_app/services.py`：节点输入组装、归一化、失败映射、N7 门禁、生成自动准备。
- `platform_app/management/commands/seed_platform_templates.py`：发布 3.3 模板并退休旧版本。
- `frontend/src/components/ProductCard.tsx`：商品卡、缩略图预览/拖拽入口、状态。
- `frontend/src/components/ImportPanel.tsx` 或现有等价文件：常驻导入区、SKU 加载态。
- `frontend/src/components/PromptEditor.tsx`：侧浮层 Prompt、逐槽加载、目标语言文案。
- `frontend/src/types.ts`：snapshot、appearance、stage、copy fields。
- `tests/test_prompt_os.py`、`tests/test_prompt_templates_v3.py`、前端对应测试：红绿验证。
- `PROGRESS.md`、`BLOCKED.md`、`docs/project/STATUS.md`：断点、阻塞和交接。
