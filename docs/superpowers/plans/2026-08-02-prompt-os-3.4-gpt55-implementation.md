# Prompt OS 3.4 GPT-5.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让商品工作台、N1–N9、文案策略、目标语言文字锁和正式生成按 3.4 规格真实跑通。

**Architecture:** 不新增表、依赖、Redis、WebSocket 或新队列。复用 `ClusterAsset`、`analysis_snapshot`、`PromptVersion`、现有上传/ERP/API、TanStack Query 和 dnd-kit。后端统一变量总线、节点归一化、N7 门禁和自动预备；前端只做紧凑操作、真实缩略图、浮层、进度和逐槽 Prompt 展示。

**Tech Stack:** Django 5.2、React + TypeScript + Vite、TanStack Query、dnd-kit、APIMart `gpt-5-nano-2025-08-07`、`deepseek-v4-pro`、`gpt-image-2`。

## Global Constraints

- 默认配置：`Shopee 虾皮 / 东南亚通用 / 1:1 / 1K`。
- 导入后整理零 AI；自动出图和正式生成缺 Prompt 时自动跑 N1–N7。
- 一个商品卡产出一套 1+8；卡内全部图片共同参与，N2 输出 `target_appearances`。
- 国家只限制语言、硬规则和禁用内容，不强制国家场景。
- N5 温度 1.6，N6 温度 0.9，其余语义节点低温。
- 不触碰 `docs/project/用户操作流程以及相关触发.md`。
- 不打印 Secret，不覆盖历史 Prompt/生成/审核，不 skip/delete/放宽测试。
