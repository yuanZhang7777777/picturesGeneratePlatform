# Prompt OS 3.1 Marketing Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 让 N5–N7 稳定产出以事实为依据、能激发使用想象和购买欲、符合目标语言且可直接交给 gpt-image-2 的 1+8 营销图 Prompt。

**Architecture:** 保留现有 N1–N9、PromptNodeTemplate、PromptVersion 和 analysis_snapshot。只给 N5 增加嵌套 creative_strategy，给 N6 本地化结果增加质量记录，再让 N7 接收结构化文案做确定性锁定检查；模板版本升至 3.1.0，不覆盖历史 3.0.0。

**Tech Stack:** Django 5.2、Python、PostgreSQL、React/TypeScript、APIMart deepseek-v4-pro、gpt-5-nano-2025-08-07、gpt-image-2。

## Global Constraints

- 权威设计：docs/superpowers/specs/2026-08-02-prompt-os-3.1-marketing-copy-design.md。
- 不新增模型、数据表、状态库、前端依赖、Redis、WebSocket 或消息队列。
- 不读取、修改、删除或提交 docs/project/用户操作流程以及相关触发.md。
- 不覆盖历史 PromptVersion、Generation、审核记录或 3.0.0 模板。
- 竞品原图仍不得进入 DeepSeek、gpt-image-2、生成参考、商品事实或导出。
- 3500 字符只约束最终单图 Prompt；图片文字最多三行并逐字锁定。
- 测试不得 skip/todo、删除、放宽断言、mock 被测核心对象或使用 || true。
- 真实付费调用和 Hermes 部署必须由主 Agent 签核；Hermes 使用 hermes-remote 与 global.lock。
